## ИИ-ассистент

Полноценный ИИ-управляющий твоей страной с гибкими настройками.

- Включается и выключается одной кнопкой в меню решений
- **6 переключателей:** бюджет, правительство, ассимиляция, колонизация, дипломатия, собственные действия
- Все ограничения по умолчанию **включены** (действия ИИ запрещены)
- Приоритет армий — выбор стран мышкой по карте
- Приоритетный враг при объявлении войны (×3 вес фронтов)
- **Оборона столицы** — резерв армии всегда остаётся в столице
- **Гарнизоны** — выбор провинций, где войска не трогаются
- Экономический режим при инфляции (только эко-постройки)
- Лёгкая застройка до порога инфляции (30%, 3 постройки/ход)

## Генералы (in development)

Система командования армиями с бонусами к боевым характеристикам.

- Найм до **8 генералов** за золото
- Бонус атаки **+15%…+50%** армиям под командованием
- Панель генералов внизу экрана — клавиша `G`
- Назначение провинций кликом по карте

## Прочие улучшения

- **Полная ассимиляция** (`M`) и ассимиляция всех людей (`N`)
- Авто-поглощение малых национальностей каждый ход
- **Карта рисков** (`K`) и маркеры партизан (`O` / `L`)
- Счётчик FPS в правом углу (настраивается)
- **Укрепполоса** — кистью выбираешь провинции для фортов и башен
- Увеличено количество портов; приоритетное строительство
- Стратегические порты на фронтах с врагами (×2.5)
- Исправлены краши: ультиматумы, ассимиляция, музыка
