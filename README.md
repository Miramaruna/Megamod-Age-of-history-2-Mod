Название: Megamod+
Создатель: Mirtemir (@Ubeber) https://github.com/Miramaruna
База: Мод сделан на основе другого мода — Megamod v6.0

━━━ ИИ АССИСТЕНТ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 • Полноценный ИИ-управляющий твоей страной
 • Вкл/Выкл одной кнопкой в меню решений
 • Настройки: 6 переключателей (бюджет, правительство,
   ассимиляция, колонизация, дипломатия, свои действия)
 • Все ограничения по умолчанию ВКЛЮЧЕНЫ (запрещено ИИ)
 • Приоритет армий — выбор стран мышкой по карте
 • Приоритетный враг при объявлении войны (×3 вес фронтов)
 • Оборона столицы — резерв армии всегда в столице
 • Гарнизоны — выбор провинций где войска не трогаются
 • Экономический режим при инфляции (только эко-постройки)
 • Лёгкая застройка до инфляции (30% порога, 3 постройки/ход)

━━━ ГЕНЕРАЛЫ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 • Найм до 8 генералов за золото
 • Бонус атаки +15%…+50% армиям под командованием
 • Панель снизу экрана (клавиша G)
 • Назначение провинций кликом по карте

━━━ ГОСУДАРСТВЕННЫЕ ПОЛИТИКИ ━━━━━━━━━━━━━━━━━━━━━━━

 • Налоги меньшинств: Льготные / Равные / Дань
